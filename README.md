# Compiladores1-Grupo-09
Repositório utilizado para o desenvolvimento do projeto do grupo 9 da disciplina de Compiladores 1, abordando conceitos fundamentais como análise léxica, sintática e semântica.

### Instruções Básicas

**Para rodar no linux:**

- Dê permissão:

`chmod +x compilador_grupo09.sh`

- Coloque o comando com o arquivo teste:

`./compilador_grupo09.sh arquivo.c`
